# WGU_Capstone_Project

Description
This is my capstone project for the Computer Science program at Western Governors University. The project uses machine learning on historical weather data to help predict if it is going to rain on a specfic day in the future. The ML model and the interface are located in the main.py file. The interface was built using streamlit and will be hosted on Streamlit Cloud.

Topic
The project's topic is to predict if it is going to rain or not by using machine learning algorithms. 

Data
The data used in this project is weather_data.cvs. This file contains daily weather data spanding over three years.
